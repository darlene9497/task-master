# TaskMaster - Personal Productivity Dashboard

A modern, client-side productivity application with user authentication, task management, and personalized dashboard features. Built with vanilla JavaScript and localStorage for data persistence

## 🚀 Live Demo

[View TaskMaster](https://task-master-eta-seven.vercel.app/)

## 🚀 Features

Authentication System

- User registration: Create new accounts with email validation
- User login: Secure login with credential verification
- Session management: Persistent user sessions using localStorage
- Auto-redirect: Smart routing based on authentication status
- Logout functionality: Clear session and return to login page

Personalized Dashboard

- Dynamic greeting: Time-based greetings (Good morning/afternoon/evening/night)
- User profile display: Shows user's name and email in sidebar
- Profile icon: Auto-generated initial from user's first name
- Real-time updates: Dashboard updates based on current user data

Dashboard Features

- Tasks page: Dedicated task management interface (dynamic template ready)
- Community board: Collaborative community page (dynamic template ready)
- Dashboard overview: Summary cards for tasks, expenses, notes, and completion rate
- Quick actions: Fast access to create tasks, track expenses, and write notes

Placeholders for Future Development

- Expense tracking
- Note taking
- Settings panel

## 🛠️ Technologies used

- HTML5: Semantic markup
- CSS3: Modern styling with custom properties
- Vanilla JavaScript: No frameworks, pure JS
- localStorage API: Client-side data persistence
- Validator.js: Email and input validation
